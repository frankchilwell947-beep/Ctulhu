# Зов Ктулху 7e — Лист Сыщика (WWII)

Character Sheet Generator для настольной ролевой игры «Зов Ктулху» 7-я редакция, сеттинг Второй мировой войны.

## Возможности

- 📝 Заполнение данных персонажа (личное дело, характеристики, навыки, оружие, биография, личные моменты)
- 🎨 5 визуальных тем (СССР, США, Третий Рейх, Япония, Китай)
- 🎲 Автоматический подсчёт половины (½) и пятой части (⅕) для всех характеристик и навыков
- ⚔️ Броски кубиков (d100 с уровнями успеха CoC 7e, кастомные формулы, преимущество/помеха)
- 🖼️ Загрузка портрета персонажа
- 📋 53 официальные профессии CoC 7e
- ➕ Кастомные навыки (добавляйте свои)
- 💾 Автосохранение в браузере (localStorage)
- 📤 Экспорт/импорт JSON, резервные копии
- 🖨️ Печать и сохранение в PDF (формат A4)
- 🌙 Тёмная тема
- 🔊 Звуковые эффекты бросков

## Использование

Просто откройте `index.html` в браузере — никаких установок или серверов не требуется.

## GitHub Pages

Этот репозиторий настроен для GitHub Pages:

1. Загрузите файлы в репозиторий GitHub
2. Settings → Pages → Source: `main` branch, `/github-pages` folder
3. Сайт будет доступен по адресу: `https://[username].github.io/[repo-name]/`

## Технологии

- Чистый HTML/CSS/JavaScript (single-file component)
- Google Fonts (Special Elite, Courier Prime, и др.)
- localStorage для сохранения данных
- Web Audio API для звуковых эффектов
