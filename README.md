# Зов Ктулху 7e — Лист Сыщика (WWII)

Интерактивный лист персонажа для НРИ «Зов Ктулху» 7-й редакции в сеттинге Второй мировой войны — с бросками по правилам CoC 7e и отправкой результатов в Discord.

## Возможности

**Лист персонажа**
- 📝 Личное дело, характеристики, навыки (52, включая пистолет-пулемёт, пулемёт, тяжёлое оружие и артиллерию), оружие, биография, инвентарь, заклинания, личные моменты
- 🎨 5 оформлений: СССР, США, Германия, Япония, Китай
- ½ и ⅕ считаются автоматически; пустой навык показывает базовое значение и бросается от него
- 💪 Бонус урона, комплекция, движение (с поправкой на возраст), максимумы HP и ОМ
- 🎓 Панель возраста по таблице CoC 7e с автоматическими проверками ОБР
- 🎲 Генерация характеристик (3d6×5 и (2d6+6)×5), кнопка «Заполнить показатели»
- 🎖 52 профессии: навыки и оружие подбираются под страну листа
- 🎒 Наборы оружия пяти армий и гражданский; «Навык %» подставляется из листа
- 🖼 Портрет, 3 слота персонажей, экспорт/импорт JSON, резервная копия, ссылка «Поделиться» (сжатая)
- 🖨 Печать листа в A4 и отдельная печать карточки персонажа
- 🌙 Тёмная тема, 🔊 звуки бросков, горячие клавиши

**Броски по правилам CoC 7e**
- Уровни успеха: критический (01), чрезвычайный (≤⅕), трудный (≤½), обычный, провал, фамбл (100; при навыке меньше 50 — 96–100)
- Сложность проверки: обычная / трудная / чрезвычайная
- Бонусные и штрафные кости (до двух): лишняя кость десятков, общая кость единиц
- Пуш (повторный бросок) и трата удачи для прохождения проверки
- Отметки развития ставятся автоматически при успехе; «📈 Фаза развития» проводит проверки
- Урон с бонусом урона (`1d4+БУ`), максимальный урон при чрезвычайном успехе атаки, проверка неисправности оружия
- Рассудок: проверки «X/Y», проверка ИНТ при потере ≥5 (временное безумие), бессрочное безумие при потере ⅕ за игровой день, таблицы приступов безумия
- Серьёзная рана, потеря сознания и «при смерти» определяются автоматически при изменении HP
- Статистика бросков, трекер состояний, упрощённая погоня по ДВИЖ

## Discord

Сайт отправляет броски в канал Discord через **вебхук** — без бота и без своего сервера. Все броски открытые: их видят все участники канала. Работает и с GitHub Pages, и с открытым локально файлом.

### Как подключить (Хранитель)

1. В Discord: **Настройки сервера → Интеграции → Вебхуки → Новый вебхук**.
2. Выберите канал для бросков (например, `#броски`), задайте вебхуку имя и аватар и нажмите **«Копировать URL вебхука»**.
3. На сайте нажмите **Discord**, вставьте адрес, нажмите «Проверить» и «Тестовое сообщение».
4. Нажмите **«Ссылка для игроков»** и отправьте её игрокам лично. Открыв её, игрок подключит свой лист к вашему каналу.

### Что появляется в канале

- Проверки навыков, характеристик, удачи и атаки: результат, уровень успеха, сложность, бонусные кости, пуш
- Урон и неисправности оружия, броски по формулам
- Проверки рассудка, временное и бессрочное безумие, приступы безумия
- Изменения HP, рассудка, ОМ и удачи (включая серьёзные раны)
- Генерация характеристик, фаза развития, трата удачи
- «📋 Представить персонажа» — карточка персонажа и файл листа в JSON для Хранителя

Сообщения приходят от имени персонажа, с портретом и цветом по результату. Какие события отправлять, настраивается в окне Discord.

### Инструменты Хранителя (🎩 Хранитель)

- **Сообщение**: повествование, раздаточный материал с картинкой, объявления
- **Запрос проверки**: «Слух, трудная, со штрафной костью» или проверка рассудка «1/1d6». Если сайт опубликован, в сообщении есть ссылка «Бросить на сайте»: она открывает лист игрока с уже выбранной проверкой
- **Бросок Хранителя**: броски за NPC, результат сразу виден в канале
- **Бой**: очерёдность по ЛВК (+50 с огнестрелом наготове), объявление порядка и ходов в канале
- **Ещё**: генератор NPC (с отправкой в канал), оценка сложности, приступ безумия, начало и конец сессии

### Безопасность

- URL вебхука работает как пароль: любой, у кого он есть, может писать в канал. Делитесь им только с игроками. Если он утёк — удалите вебхук в Discord и создайте новый.
- Адрес вебхука хранится только в браузере (`localStorage`) и не попадает в экспорт, бэкап и ссылки «Поделиться».
- Упоминания (`@everyone`, `@here`, роли) в сообщениях отключены.

## Использование

Откройте `index.html` в браузере — установка и сервер не нужны. Данные сохраняются в браузере автоматически; для переноса на другое устройство используйте экспорт или бэкап.

Сохранения из прошлых версий переносятся автоматически при первом открытии.

### GitHub Pages

1. Загрузите файлы в репозиторий GitHub.
2. **Settings → Pages → Source**: ветка `main`, папка `/ (root)`.
3. Сайт будет доступен по адресу `https://[username].github.io/[repo-name]/`.

Ссылки «Поделиться», приглашения Discord и «Бросить на сайте» работают у других людей, только когда сайт опубликован.
