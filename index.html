🎯 Сложность, кости, пуш, удача

  • Сложность: обычная — нужно ≤ навыка, трудная — ≤ ½, чрезвычайная — ≤ ⅕.
  • Бонусная кость: бросается ещё одна кость десятков, берётся лучший (меньший) результат. Штрафная — худший. Не более двух; бонус и штраф взаимно гасятся.
  • Пуш (повторный бросок): провал можно перебросить один раз, описав новый подход. Нельзя для боя, рассудка и удачи. Провал пуша — серьёзные последствия.
  • Трата удачи: после броска очки удачи 1:1 уменьшают результат. Нельзя для проверок рассудка и удачи, урона, фамблов и пуша. За успех, купленный удачей, отметка развития не ставится.

🏃 Движение и возраст

  • ДВИЖ 7: ЛВК и СИЛ меньше ТЕЛ; 9: ЛВК и СИЛ больше ТЕЛ; иначе 8.
  • Возраст: с 40 лет −1 к ДВИЖ за каждое десятилетие; снижаются СИЛ/ВЫН/ЛВК и ШАР, растёт число проверок ОБР (см. панель возраста).

🧠 Рассудок

  • Проверка «X/Y»: d100 ≤ текущего САН — теряется X, иначе Y. Фамбл — максимум Y.
  • Максимум САН: 99 − Мифы Ктулху. Начальный САН = МОЩ.
  • Временное безумие: потеря ≥ 5 за раз → проверка ИНТ; при успехе — безумие на 1d10 часов и приступ.
  • Бессрочное безумие: потеря ≥ ⅕ рассудка за игровой день.
  • САН = 0: безумие навсегда, персонаж выходит из игры.
  • Восстановление: психоанализ +1d3, награды Хранителя за сценарий, развитие навыка до 90%+ даёт +2d6.

❤ Здоровье

  • Макс. HP: (ВЫН + ТЕЛ) / 10, с округлением вниз.
  • Серьёзная рана: урон ≥ ½ макс. HP за раз → проверка ВЫН, иначе потеря сознания.
  • 0 HP: без серьёзной раны — без сознания; с серьёзной раной — при смерти (проверка ВЫН каждый раунд, пока не стабилизируют Первой помощью).
  • Урон больше макс. HP за один раз — мгновенная смерть.

⚔ Бой

  • Очерёдность: по убыванию ЛВК; огнестрел наготове даёт +50 к ЛВК.
  • Защита в рукопашной: уклонение или контратака (встречная проверка).
  • Огнестрел: от пуль не уклоняются — можно нырнуть в укрытие.
  • Чрезвычайный успех атаки: максимальный урон (колющее оружие и пули — плюс ещё один бросок урона).
  • Неисправность: результат ≥ значения неисправности — оружие заклинило.

✨ Магия и развитие

  • Макс. ОМ: МОЩ / 5. Заклинания стоят ОМ и САН.
  • Фаза развития: для каждого отмеченного навыка d100; результат больше навыка (или 96+) — навык +1d10.
  • Мифы Ктулху и Кредитоспособность не развиваются отметками.

Как подключить (нужны права «Управление вебхуками»)
  1. Хранитель открывает в Discord Настройки сервера → Интеграции → Вебхуки → Новый вебхук.
  2. Выбирает канал для бросков (например, #броски), даёт вебхуку имя и аватар — например, щупальца Ктулху.
  3. Нажимает «Копировать URL вебхука» и вставляет его ниже.
  4. Кнопка «Ссылка для игроков» создаёт приглашение: игрок открывает его — и сайт подключается сам.

🔑 URL вебхука работает как пароль: любой, у кого он есть, может писать в канал. Делитесь им только с игроками. Если он утёк — удалите вебхук в Discord и создайте новый. Адрес хранится только в этом браузере и не попадает в экспорт, бэкап и ссылки «Поделиться».
